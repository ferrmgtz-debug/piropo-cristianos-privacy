Política de Privacidad

Aplicación: Piropos Cristianos
Desarrollador: Ghozek
Última actualización: 3 de septiembre de 2026

En Ghozek respetamos la privacidad de las personas que utilizan Piropos Cristianos. Esta Política de Privacidad explica qué información puede procesarse al utilizar la aplicación, para qué se utiliza y con quién puede compartirse.

1. Información que recopilamos

Piropos Cristianos no requiere crear una cuenta ni iniciar sesión y no solicita directamente al usuario su nombre, correo electrónico, número telefónico, contactos, ubicación, fotografías, audio ni información financiera.

Los piropos marcados como favoritos se almacenan localmente en el dispositivo del usuario. Estos favoritos no se envían a Ghozek como parte de una cuenta en línea.

2. Generador de contenido mediante IA

La aplicación incluye una función opcional para generar piropos mediante inteligencia artificial. Cuando el usuario utiliza esta función, el texto que introduzca y los parámetros necesarios para generar el contenido pueden ser enviados al servicio Google Gemini API para procesar la solicitud y devolver una respuesta.

Piropos Cristianos no solicita información personal para utilizar esta función. Sin embargo, si el usuario decide introducir información personal dentro de su propia solicitud, esa información puede formar parte del contenido enviado al servicio de IA. Por ello, recomendamos no introducir contraseñas, datos financieros, información médica, documentos de identidad u otra información sensible.

El tratamiento de las solicitudes y respuestas de Gemini está sujeto también a las condiciones y políticas aplicables de Google al servicio utilizado. Para obtener información actualizada sobre el tratamiento de datos de la API de Gemini, consulte la documentación oficial de Google.

3. Datos técnicos y conexión a Internet

La aplicación utiliza conexión a Internet cuando necesita comunicarse con el servicio de generación mediante IA. La aplicación no utiliza deliberadamente la conexión a Internet para recopilar o vender perfiles personales de los usuarios.

4. Publicidad y analítica

La versión de Piropos Cristianos cubierta por esta política no utiliza anuncios publicitarios ni integra servicios de analítica publicitaria para crear perfiles de los usuarios.

5. Servicios de terceros

Para la función de generación mediante IA puede utilizarse Google Gemini API, un servicio proporcionado por Google. El contenido necesario para procesar la solicitud puede transmitirse a dicho servicio.

Google puede procesar dicha información conforme a sus propias condiciones, políticas de privacidad y condiciones específicas del servicio utilizado por el desarrollador.

6. Almacenamiento y eliminación de datos

Los favoritos guardados por el usuario se almacenan localmente en el dispositivo. El usuario puede eliminarlos desde las opciones de la aplicación. La desinstalación de la aplicación también elimina los datos locales asociados a ella, sujeto a los mecanismos de copia de seguridad del sistema operativo Android.

Ghozek no mantiene una cuenta de usuario de Piropos Cristianos ni una base de datos propia de perfiles personales de usuarios.

7. Seguridad

Ghozek adopta medidas razonables para proteger la información procesada por la aplicación. Las comunicaciones con servicios externos utilizados por la aplicación se realizan mediante conexiones de red seguras cuando dichos servicios las proporcionan.

8. Menores

Piropos Cristianos no está diseñado específicamente para niños. No solicitamos deliberadamente información personal de menores.

9. Cambios en esta Política de Privacidad

Podemos actualizar esta Política de Privacidad cuando cambien las funciones de la aplicación, los servicios utilizados o los requisitos legales y de las tiendas de aplicaciones. La fecha de última actualización se mostrará al inicio de esta página.
